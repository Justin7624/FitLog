# FitLog original body mesh

`body-mesh.js` is an original, programmatically sculpted anatomical template created for FitLog 4.0 from authored cross-section coordinates and surface functions in `tools/build_mesh.py`. No external human scan, MakeHuman/SMPL asset, texture, or downloaded model is included. The mesh and its authored cross-section parameters are offered under **CC0 1.0 Universal** (SPDX: `CC0-1.0`): https://creativecommons.org/publicdomain/zero/1.0/ . The build script depends on separately licensed NumPy, SciPy, scikit-image and trimesh; these libraries are not distributed in the app and are not required for using it. FitLog's browser renderer and fitter use original JavaScript and browser APIs; no third-party renderer is bundled. An exported fitted mesh may describe personal dimensions, so treat such files as private regardless of the base mesh license.
